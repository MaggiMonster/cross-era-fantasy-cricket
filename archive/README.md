# Archive: old video-generation scope

This folder holds the project's original scope, "Cross-Era Fantasy Cricket":
pose extraction from cricket videos, image-to-video generation, era film filters
and evaluation. It was replaced by Cross-Era Cricket Duel and is no longer run or
maintained.

- `pose/`, `generation/`, `era_filters/`, `evaluation/` - the old code.
- `tests/` - the old tests.
- `docs/` - the old proposal, pose interface and Milestone 2 status.

Commands in these files assume the old layout, with the folders at the repo root.
Virtual environments are not portable, so recreate one before running anything.
